# tabSafe

tabSafe is a privacy-first medication and supplement tracking application. All sensitive health data is encrypted and stored locally on the user's device. This app avoids using centralized accounts.
tabSafe follows a local focused design: health data is encrypted on the device, the server never sees plain text (if used at all), authentification happens on the client, and notifications avoid sharing sensitive information. 

# Repository Structure 
* client/ — User facing application (UI, encryption, local storage, reminders)
* server/ — Optional encrypted backup services
* expo-client/ - frontend implementation 
* tests/ — Security testing (not sure if we're doing this?)
